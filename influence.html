Influence games and the most influential nodes

Irfan & Ortiz, “A Game-Theoretic Approach to Influence in Networks”, AAAI 2011 (IO below). You can build a linear influence game, enumerate its stable outcomes, and pick the nodes whose choices pin down a target outcome.

Model (IO Defs. 1 and 3). Each player chooses xi ∈ {−1, +1} (reject / adopt). In a linear influence game (LIG) the influence on i is fi(x−i) = Σj≠i wji xj − bi, and the payoff is ui = xi fi. Here wji is the influence of j on i (an arc j → i) and bi is a threshold. The best response is +1 if fi > 0, −1 if fi < 0, and either if fi = 0. Stable outcomes are the pure-strategy Nash equilibria (PSNE).

Most influential set (IO Def. 2). Fix a desirable PSNE x* (goal g) and prefer small sets (h). A set S is most influential if x* is the only PSNE x with xS = x*S, and no smaller set does the same.

Greedy (IO) vs exact

IO show the problem is equivalent to minimum hitting set (Thm 10). Each other PSNE y contributes the set of players where y differs from x*, and S must hit all of them. The greedy rule repeatedly picks the player whose target action is shared by the fewest remaining PSNE. That gives a (1 + log h) approximation, with h the number of PSNE.

4 · Tractable special cases

Thm 4: non-negative influences

With all wji ≥ 0 the game is supermodular. Start from all −1 and let every player with fi > 0 switch. Nobody ever wants to switch back, so a PSNE is reached within n rounds. Try the “slide 60” preset.

Prop 5: symmetric influences

If wij = wji, then Φ(x) = Σt xt(Σi≠t xiwit/2 − bt) is an exact potential, so a PSNE exists. With all thresholds 0 this is a party-affiliation game, and finding a PSNE is PLS-complete (Fabrikant et al. 2004).

Thm 7: TreeNash for LIGs on trees in O(nd)

For an LIG whose underlying graph is a tree, IO compute each downstream table entry from one linear inequality. For each own action xi, a parent with exactly one feasible action x̂k goes into Pa₁ and contributes x̂kwki. A parent with both actions feasible goes into Pa₂ and is set to the action that helps i most, contributing |wti|. The entry is 1 iff xi(xjwji + ΣPa₁ x̂kwki − bi) + ΣPa₂|wti| ≥ 0. 5 · Counting PSNE is #P-complete, even on a star (Thm 8(3))

IO reduce #KNAPSACK to counting PSNE. The construction is a star with actions {0, 1}, as in their proof. The centre v₀ influences every leaf with weight 1, leaf i influences the centre with weight −ai, the centre's threshold is −W, and every leaf's threshold is 1. In every PSNE the centre plays 1, the leaves are indifferent, and the centre's best response holds iff Σaixi ≤ W. So the PSNE are exactly the feasible knapsack subsets.

6 · Replicating the random-LIG experiment at small scale

IO's setup: 25 nodes, each ordered pair an arc with probability 0.5, each weight −1 with “flip probability” p (else +1), and 100 graphs per p. They report that the number of PSNE grows as negative weights dominate (Fig. 3; about 200 PSNE on average at p = 1, read from the plot). For all-negative games, greedy is within optimum + 1 in 87% of trials and within + 2 in 99%. Our rerun uses the backtracking search described above (without NashProp). It runs in a background thread in your browser.

Assumptions we had to make. IO do not state, for this family: (i) the thresholds, so we use bi = 0, as in their preferential-attachment experiment; (ii) which PSNE is the target, so we draw one uniformly at random per graph; (iii) the greedy tie-breaking rule, so we use lowest index; (iv) how the confidence intervals are computed, so we use mean ± 1.96·sd/√m. Graphs without a PSNE are skipped for the influence statistics. The numbers will therefore not match the paper exactly.
